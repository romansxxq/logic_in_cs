Програма перевіряє, чи завершиться інша програма, але чекає тільки 10 секунд.

Якщо час вийшов, це ще не означає, що програма зациклиться, вона може завершитися пізніше. Наприклад, test.py має нескінченний цикл і не завершується.

Для будь-якого обмеження часу може існувати програма, яка завершиться трохи
пізніше. 

Тому неможливо створити загальний алгоритм, який для кожної програми точно визначає, завершиться вона чи буде працювати нескінченно. Це називається проблемою зупинки.
