Алгоритм може перевіряти послідовність поступово, але не може гарантувати знаходження будь-якого шаблону в довільній нескінченній послідовності за скінченний час. Якщо шаблон розташований дуже далеко або взагалі відсутній, пошук може не завершитися. На практиці машинне навчання використовують для пошуку ймовірних закономірностей у тексті, музиці та інших даних, але це не гарантує виявлення будь-якого можливого шаблону.
